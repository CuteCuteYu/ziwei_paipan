# 紫微斗数 · 手工排盘全过程

## 快速开始

1. 双击打开 `紫微斗数排盘全过程.html`；
2. 填写生辰小帖：
   - **历法**：公历 / 农历双模式（农历模式下拉自动列出大小月与闰月）；
   - **出生时刻**：钟表时间，自动划分十二时辰；
   - **出生地（经纬度）**：内置 36 个主要城市下拉，或自定义经纬度；默认开启**真太阳时校正**（钟表时 ± 经度差×4 分 ± 均时差，校正跨子夜会自动进退历日）；
   - **性别**：决定大限顺行 / 逆行；
3. 点「开始排盘」，用「下一步 / 自动演示 / 直接成盘」推进十二步；
4. 第十二步「全盘告成」后，点控制栏「**导出命盘 MD**」下载命盘文件。

## 导出文件结构

「导出命盘 MD」生成 `紫微命盘_乾（坤）造_干支年月日时.md`，共五部分：

1. **一、基本信息** —— 造别、真太阳时与钟表时刻、出生地经纬度与校正明细、农历、时辰、五行局、命身宫、命主身主、生年四化、行限、日柱；
2. **二、命盘（盘面方位）** —— 4×4 表格复刻传统盘面（上巳午未申、右酉戌、下亥子丑寅、左辰卯，四格中宫分置生辰/局/主/化限），每宫含宫干支、宫名、主星（四化角标）、辅煞星、大限岁段；
3. **三、十二宫明细** —— 按命宫→父母顺序的 12 行速查表；
4. **四、推演摘要** —— 十二步每步的结论，保留手工推演痕迹；
5. **五、方法注记** —— 本盘所采用的历法与流派约定。

## ⭐ 把导出的 MD 直接交给 AI 解读

导出的 Markdown 文件**自包含全部盘面信息与方法注记**——AI 无需另行排盘即可直接解读。两种用法任选：

- **作为附件**：把导出的 `.md` 文件直接拖入 / 上传给任意 AI 助手（DeepSeek、ChatGPT、Claude、Gemini、豆包、Kimi 等）；
- **作为正文**：用文本编辑器打开，全选复制，粘贴进对话框。

## 排盘方法约定（供核验与 AI 参照）

- 年干支以**农历正月初一**为界（另有以立春换年一派）；
- 时辰以**真太阳时**为准：钟表时（东经 120° 平太阳时）＋（经度 − 120°）× 4 分 ＋ 均时差（近似式，误差约一分钟）；晚子时（23 时后）归当日；
- 闰月：十五（含）之前作本月论，之后作下月论；
- 大限用虚岁，起限岁数即五行局数；流年命宫即流年地支所在之宫；
- 星曜范围止于十四主星与常用辅煞（六吉、六煞、禄存天马、鸾喜刑姚）；博士十二神、长生十二神等未纳入。

页面核心算法经 130 余项自动化断言验证（农历换算锚点、干支锚点、紫微安星对照《全书》古表、真太阳时校正、Markdown 导出结构等）。
